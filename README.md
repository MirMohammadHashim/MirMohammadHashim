## Featured project: [Credit Book](https://github.com/MirMohammadHashim/credit-book)

A three-tier web app on AWS (a digital *udhaar khata* for shopkeepers), built by hand to practise real cloud engineering.

[![Credit Book architecture](https://github.com/MirMohammadHashim/credit-book/raw/main/docs/social-preview.png)](https://github.com/MirMohammadHashim/credit-book)

| Area | What I built |
|---|---|
| **Network** | VPC with public and private subnets. MySQL on RDS has no public access and is reachable only from the backend's security group |
| **Security** | No SSH (Session Manager), secrets in Parameter Store, least-privilege IAM role, bcrypt passwords, parameterised SQL |
| **Operations** | Dockerised Flask API on EC2, CloudWatch logs and an alarm with email alerts, cost-aware design (about $0.035/hour) |
| **Documentation** | Architecture diagram, security notes, cost breakdown, deployment guide and a real troubleshooting log |

**[View the repository](https://github.com/MirMohammadHashim/credit-book)**
